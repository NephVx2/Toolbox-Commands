EN: here is a graphics Toolbox and its separate catalog to put in the same folder which allows you to launch different Windows commands. This avoids having to search for certain more or less complex parameters. For sensitive orders written in orange, you will have a confirmation request before the order is executed. All commands are explained at the bottom of the launcher when you hover over each command. "For Gamers", there is a “Performance” category where you can disable or re-enable Memory Integrity (HVCI) and, if you wish, use a command to disable or re-enable Virtualization-Based Security (VBS). Depending on your PC, this may improve performance and thus increase your FPS. To do this, start by disabling Memory Integrity (HVCI), for example, and then restart your PC. Next, run the “Hardware Virtualization Status (Hypervisor / VBS)” command; this will show you whether HVCI or VBS has been successfully disabled. Then test it by launching your game and check during gameplay whether you’ve seen an increase in FPS or not. When you’re done playing, simply re-enable HVCI or VBS—whichever you chose—and restart your PC. Launch the game launcher again and verify that everything is properly re-enabled using the “Hardware Virtualization Status (Hypervisor / VBS)” command.
  I'll let you explore the other commands in this handy Toolbox.
